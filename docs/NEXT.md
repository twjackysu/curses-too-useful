## ★ 垂直切片：腐敗之森入口的 3 分鐘

現在有的：諾恩一個人走進森林 → 席菈等在瘴氣前面，問能不能一起去（兩個回答）→ 結伴 → 瘴氣（她戴防毒面具；諾恩中毒 → 回血，完整的反轉回饋）→ 兩人講四句 → 三隻劇毒史萊姆：劍是三下連段（右邊劈一刀 → 從左肩橫掃到右邊 → 收尾的大劈；每一刀有劍光、砍中的地方閃一道刀痕：平常鏽色、反轉中金色、收尾最大），每砍中一刀給自己中毒＋一層流血（越砍越快、越快越重）；席菈慌了射錯一瓶（重度麻痺＋防禦歸零 → 出手快 150%＋受傷少 80%）→ 一刀一隻清場 → 戰後對話（兩個回答）→ 「未完待續」。她在鏡頭外喊的話會放在畫面下方「席菈：……」。Jacky 11/14 玩過兩次：「還行」；相遇、面具、誤射、戰後對話、連段、一刀一隻、劍光、刀痕這幾段他還沒玩過。

1. **砍下去要有感覺（還剩的）**：劍光、揮劍聲、刀痕、超頻收尾不再整片白、第二下橫掃重做都有了（11/15）。接下來：①**第一、三下是同一個形狀**（身體右邊的月牙，第三下大一號）——想讓第一下不一樣，只能在「劍在身體右邊或頭上揮、劍身橫對著鏡頭」的範圍裡改（D-284；例：反手從左上劈到右下）。改之前先量劍光在畫面上的面積（做法在 `04`「出手的動作」），比 0.6 m² 小就不要 ②第二下剛開始揮的那一刻，左邊的劍光有一小塊比較厚（拉開時劍晃了一下也被記進去）：試把 `PlayerController.TRAIL_WINDOW` 的開頭往後挪一點，三下都要重拍 ③收尾那一刀砍中的聲音還是借 `blunt_weak` ④超頻時每一刀的打擊停頓要不要短一點（現在砍倒一隻停 0.12 秒，出手 0.22 秒一刀時佔了三分之一——要有人玩過才知道）⑤程式人偶三下同一個姿勢（模型都在的時候看不到）⑥**出手的拉開幾乎看不到**：拉開只有 0.07 秒，動作卻花 0.15 秒才接上去（`Puppet` 裡 `anim.play` 的第二個參數）。11/15 試過縮到 0.06 秒：拉開清楚了，但砍中的那一刻劍已經往右帶、第一刀的刀痕變斜，而且每台機器不一樣（CI 紅，退回）。要做的話連「刀痕取哪一段的方向」（`SlashTrail.sweep()` 取最近幾個取樣，跟幀率有關）一起改成照時間取。
2. **席菈再好一點**：①手弩的握把有沒有在手心（`Sera.CROSSBOW_ROT`／`CROSSBOW_OFFSET`；`BURST_RES=1920x1080 --burst-on=vial --cam-yaw=90`）②走過瘴氣要有反應（劇本：慌張地找防毒面具）③按鍵向她要藥（`SeraBrain.request()` 已經有，接上按鍵與第二種藥）④射藥與藥瓶碎掉的聲音現在借用 `whoosh`、`glass_clink` ⑤戰後對話的選項畫面拍一張看排版 ⑥相遇那一段加一點演出（她看著瘴氣猶豫的樣子、開口時鏡頭帶到她的臉）⑦防毒面具現在是程式拼的，玩的距離看得出來；要近看再排 Tripo（物件約 20 點）⑧畫面下方「席菈：……」那一行字後面沒有底，疊在亮的地面上時對比普通（拍法：`--joined --at=0,-5 --hold=move_forward`，`BURST_EVERY=30 BURST_CROP="0,0,1,1"` 從第 120 幀起）。
3. **森林再好看一點**（某一輪只動畫面時）：地面還是平的——加緩坡或土堤（先只做玩家走不到的外圍）；樹只有一種模型；史萊姆是紫的、場景也是紫的——給敵人一圈冷色的輪廓光或把牠的顏色往螢光綠偏；天空加星星與月亮；土丘的邊緣從側面近看還有一圈。改前先 `scripts/shots.sh forest --save-baseline`。
4. **要有人玩過才知道的**：連段的手感（0.45 秒內接得上嗎、第三下夠不夠重）；一刀一隻會不會太簡單（現在沒吃藥也只要 7 刀）；停手 5 秒後再砍，第一刀整個畫面又閃一次會不會太吵（太吵的話：自己的劍給的狀態只演小的——圖示翻面＋劍亮，不閃整個畫面）；被史萊姆連續撞時畫面一直閃；出手快 150% 手感會不會太飄；四個音效（`curse_sting`、`reversal_shatter`、腳步、揮劍的 `slash`）沒有人聽過；劍光會不會太搶戲（收尾那一刀從側面看是很大的一片）；刀痕會不會太長（現在 1.9 m，史萊姆才 0.8 m 高；收尾 2.9 m）。
5. **戰鬥變長之後要處理的**（教學戰幾秒就打完，看不出來）：平常的藥瓶（×1.35）會幫重度麻痺（×2.5）續時間——同一種狀態只留最強的強度（做法：弱的來源不續強的時間，或強度跟著時間退）。「越快越重」讓傷害跟出手速度一起漲（最多 ×3.1），之後的敵人與 Boss 的血要照「有吃到增益」來定。
6. 切片好玩了再擴：森林完整版 → 祭壇 Boss → 公會大廳 → 城鎮（`13` 的場景表）。**做公會大廳（節點 1）的時候**：兩人在那裡先見到面（席菈縮在角落、被雷歐一起罵），森林口那段對話的自我介紹要跟著改短（D-280）。好感度現在只記數字（`sera.affinity`），還沒有地方看。

## 小事（改到的時候順手）

- `docs/design/04-architecture.md`「還沒整理的舊東西」那一節。
- `statuses.json` 的 `boss_miasma`、道具 `sera_poison_vial`（`PotionBelt`）現在沒有場景在用：做 Boss、背包時用上，用不上就刪。
- `StatusEffects.attack_speed()` 的註解寫「畫面上寫快 36%」——畫面上沒有寫流血快多少（只有層數），改到那個檔的時候把註解改對；要不要在狀態列寫出百分比另外決定。
- 沒有經過瘴氣就先砍到東西（只有開發旗標 `--at` 做得到）時，第一次反轉的橫幅寫的是「中毒 → 回血」，沒提流血；正常玩一定先過瘴氣。
- 標題畫面的背景換成新遊戲的（現在是舊的鐘樓剪影）。
- **★1 ⑥ 用得到——第一刀刀痕方向的測試為什麼每台機器不一樣**（11/15 09:26 那一輪查到的；那一輪跟 10:00 那一輪撞在同一件事上，程式沒有推）：`test_norn_strike_marks_the_slime_along_the_blade` 一載入玩家場景就出手，量到砍中的那一刻（0.19 秒）劍尖還在拉開的位置，`blade_sweep()` 拿到的是拉開的方向。看起來是剛載入的那一幀特別長，出手的時鐘（`Puppet.action_time`）先跑了約 0.1 秒、模型的動作沒跟上（這一句是推測）。出手前先 `for i in 6: await tree.process_frame` 讓那一幀過去，連跑三次方向都一樣（那時候測的是另一組動作，不是現在 main 的）。真的遊戲裡第一刀剛好卡一下時刀痕會不會也歪，還沒看過。
- **★1 ① 用得到——「反手從左上劈到右下」那一輪試過了**（沒進 main；接法 0.15 秒、玩家鏡頭連拍看過，**沒有量面積**，要用先照 `04` 的做法量）：第一下 `swing({"twist": 44, "lean": -4, "r": (10, 120, 60, 往內轉 55), …}, {"twist": -4, "lean": 14, "r": (6, 60, 8), …}, {"twist": -40, "lean": 16, "r": (40, 36, 10), …}, 1.0)`（左手照舊）：弧從頭頂上方斜到右下，跟另外兩下看得出不一樣，但沒有比原本的月牙大。「往內轉」是上臂繞自己的軸轉（`arm_pose` 的 `rot` 最前面多一步 `((t - h).normalized(), -sgn * roll)`），沒有它手舉不到左肩上面。第三下 `swing({"twist": -42, "lean": -14, "r": (78, 160, 92), …}, {"twist": 14, "lean": 30, "r": (0, 44, 4), …}, {"twist": 40, "lean": 34, "r": (-30, 24, 6), …}, 1.7)`：劍從左後方繞過頭頂劈到腳前，劍光是從諾恩左邊繞過頭上到右邊的一大圈，看起來比右邊那道月牙大；劈下去的後半段被他自己擋住。估劍尖的快辦法：`measure_action.py` 印的「手＋0.72 × 前臂方向」跟遊戲裡的劍尖差不多。

- 席菈走路沒有腳步聲：接 `Puppet.footfall`（做法看 `PlayerController`，小聲一點）。
- 程式人偶（沒有模型時的替身）的步頻還是舊的算法，跟模型不完全一樣；模型都在的時候看不到。
- `scripts/shots.sh forest --fetch-baseline` 抓不到基準（`screens` release 沒有 `forest-*.png`）：看 CI 有沒有在上傳，沒有就把那個選項拿掉或補上傳。
