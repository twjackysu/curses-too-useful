  - 魔像：只有兩招（重拳、震地），動作借用人的第一下與第三下劈砍；吼、凝視、跪下只是整個人前後仰；被砍沒有反應（不會後仰是設計，但也沒有別的回饋）；胸口的核心開了之後看不出來（只有畫面中間那行字）；粉碎的那一刀只有一盞強光＋一團光點，沒有特寫、沒有慢動作以外的演出（那一刻諾恩貼在牠面前，鏡頭裡魔像佔滿畫面）；倒下是跪 → 往後仰倒 → 躺幾秒 → 沉進地面，核心沒有掉出來（劇本結尾諾恩是扛著核心回公會的）。
  - 石化凝視：地上那道光在綠色的石板縫上不算顯眼（改成紫的、加寬之後連拍看得到，但沒有人玩過）；打出去只有一盞強光，沒有「一道視線掃過全場」的樣子；席菈被石化是整個人蓋一層灰（遠看只是變灰），解除沒有碎裂的演出；雷歐小隊不會被石化。
  - 霸體無敵的金光：第一版把諾恩整個人蓋成一尊金色的像，調淡了（`PlayerController.BODY_GLOW_FILL` 0.28 → 0.1：金色的輪廓、衣服看得到）；8 秒會不會太久、要不要有別的提示（「現在打不動他」）沒有人玩過。
  - 雷歐小隊：站著的模型放倒，手舉著；不擋路（人與魔像都會穿過去）；戰鬥中沒有反應（只有雷歐第一次喊一句）；打完還是躺著。
  - 開打的頭幾秒字很多：光環的說明兩行、雷歐一句、席菈一句（面具的濾芯）同時在畫面上，魔像的第一拳也在這時候來。要錯開就把席菈那一句延後幾秒。
  - 抵達的那段話：魔像在旁邊舉著拳頭不動（等對話講完）；鏡頭只拍講話的人，沒有帶到魔像；席菈與諾恩講話時沒有面向雷歐。
  - 禁藥：飛的樣子跟平常的藥瓶一樣（只是桃紅色、砸開有煙）；席菈裝填的那幾秒只是站著（沒有裝填的動作、沒有進度）。
  - 場景：斷柱與台階是程式拼的圓柱（看得出一面一面的）、符文是幾格亮幾格暗的方塊；祭壇在石板北邊只是擺設（劇本說雷歐他們「誤觸了祭壇機關」——沒有演）；沒有從森林走過來的過場（走到路口直接換關卡、沒有淡出淡入）；光環的波紋是細細的一圈；魔像醒著時石板縫的綠光調到很暗了（一開始太亮、蓋過地上那道光）。
  - 換關卡之後 `--at` 這類開發旗標也會套在新的一關（從森林走過去拍祭壇時位置會跑掉）。
  - 聲音都是借的：吼＝`brace_warn`、凝視＝`curse_sting`、重拳與震地＝`blunt_weak`、腳步＝`step_heavy`；祭壇這一關沒有自己的環境音與配樂。
  - 打完之後是「未完待續」，可以在石板上繼續走；回公會的結尾在 ④。
