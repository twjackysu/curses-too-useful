# 13　第一章實作計畫

劇本：[`../story/chapter-1.md`](../story/chapter-1.md)（Jacky 2026-11-14）。這份寫「怎麼做、先做什麼、用現有的什麼」。做完一項就在這裡打勾；細的待辦寫 NEXT。

## 核心循環（每個設計決定都回頭對這一句）

**故意去吃異常狀態 → 看它反轉成金色增益 → 用增益打爆敵人。** 陷阱、毒霧、詛咒裝備、席菈射來的藥水，都是「補給」。

## 反轉的回饋（劇本第三節，最優先做好）

吃到異常狀態：畫面邊緣閃紫／暗紅 → 0.3 秒後玻璃碎裂聲 → 轉成金色光效；HUD 上紅色 Debuff 圖示翻成金色 Buff 圖示。諾恩的劍在有反轉中的狀態時裂縫透金光。**做法**：`ReversalCue` 是唯一的時間軸，`StatusEffects.changed("start")` 觸發；之後的新狀態不用再寫回饋。

## 現況（2026-11-16 早上；①、②、③ 做完，下一段是 ④）

舊劇情的關卡與角色都砍了（2026-11-14，D-273），只留通用底層（清單在 [`04-architecture.md`](04-architecture.md)）。現在標題按「新遊戲」會進**腐敗之森**，一路可以玩到**廢棄祭壇打倒魔像**：

- **① 入口（節點 2）**：諾恩拿【瘴氣生鏽鐵劍】一個人走進來 → 席菈（【鍊金藥瓶手弩】）在瘴氣前面猶豫，他走近了她問能不能一起去 → 結伴，她戴上防毒面具 → 走進瘴氣中毒、反轉成回血 → 兩人講四句 → 三隻劇毒史萊姆（三下連段、越砍越快越重；席菈慌了射錯一瓶 → 出手快 150%＋受傷少 80%）→ 一刀一隻 → 戰後對話。
- **② 森林完整版（時段 B）**：戰後那段話講完跳「探索解鎖」、右上角出現目標清單 → 往北的森林：三種要故意踩的陷阱（毒氣噴發口、麻痺蜘蛛網、腐敗野果）、三種新敵人（黴菌史萊姆、瘴氣狼、孢子樹人）、席菈輪流射兩種藥＋按 Q 要【致盲煙霧彈】、營火（休息存檔、她的過去、解鎖連攜）、毒沼最深處的詛咒寶箱（衰弱詛咒 → 【不祥的裂刃】）→ 採滿五朵夜光毒蕈聽到慘叫 → 走到祭壇路口，換到下一關。
- **③ 廢棄祭壇 Boss（節點 3）**：走上石板，雷歐小隊倒在地上、【深淵疫病魔像】舉著拳頭 → 三人講幾句 → 魔像轉過來；走進疫病光環（全能力下降＋失血 → 全能力提升＋回血）→ Boss 戰（重拳、震地）→ 生命剩一半狂暴，席菈退到後面裝禁藥 → 石化凝視：地上一道光從魔像連到她，諾恩站上去擋住（石化 → 霸體無敵；沒擋到她被石化、過一陣子再來一次）→ 她射出【混沌大災難藥劑】，諾恩的下一刀粉碎核心 → 戰後對話（兩個回答）、拿到魔像核心 →「未完待續」。

規則在 [`02-gameplay.md`](02-gameplay.md)，劇本沒寫到的地方怎麼定的在 `DECISIONS.md` 的 D-291、D-292。**②、③ 沒有人玩過**；細修都記在 NEXT 的打磨清單。
