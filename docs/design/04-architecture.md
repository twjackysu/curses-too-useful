# 04　架構、程式地圖與開發工具

原則：**邏輯是純資料類別、場景只負責顯示**，所以雲端 session 沒有 GPU 也能用 headless 測試驗證大部分行為。2026-11-14 重新開始時只留了跟劇情無關的底層（D-273）；舊的東西在分支 `archive/pre-restart-2026-11-14`。

## 技術決定

- Godot 4.7.2 stable（標準版，版本固定在 `scripts/get-godot.sh`）、GDScript＋靜態型別（沒加型別視為錯誤）、不用 C#、Forward+。平台 Windows 64-bit；CI 順便匯出 Linux 跑 smoke test。
- 玩家看得到的字一律走翻譯 key（`game/i18n/strings.csv`，欄位 `keys,en,zh_TW`）；JSON 資料裡只放 key。
- 建置時產生的東西（字型子集、音效、轉好的模型）不進 git；什麼進 git 看 [`14-repo-and-assets.md`](14-repo-and-assets.md)。

**加東西的做法**

- 新關卡：繼承 `StoryLevel`、場景裡放 `Spawn`／`Player`／`Hud`／`PauseMenu`／`DialogueBox`，在 `Game.LEVELS` 與 `CHECKPOINT_LEVELS` 登記；劇情只透過 `Game.session.set_flag()` 推進任務。
- **劇情走到另一個關卡**：下一個任務階段的 `checkpoint` 在 `Game.CHECKPOINT_LEVELS` 登記成別的關卡；這一關設完旗標（任務推進、自動存檔）就叫 `Game.go_to_checkpoint_level()`。新關卡的 `_ready` 照任務階段決定從哪一拍開始（看 `RuinedAltar`）。測試把關卡直接掛在 root 底下，所以先 `Game.change_scenes = false`（只記下 `last_level_request`，不真的換場景）。
- **室內的關卡**（看 `GuildScenery`）：牆、天花板、門、窗都只做「朝屋裡的那一面」（`QuadMesh`，背面不畫）——過肩鏡頭退到牆外的時候看得進來，不會被推到諾恩背上。所以牆上的木柱、橫樑是畫在牆的 shader 裡的（做成盒子的話鏡頭在牆外會看到它們的背面）；屋裡獨立的東西（樑、迴廊、樓梯）才用盒子。牆與家具沒有鏡頭會撞的碰撞（第 1 層只有地板）：擋人的東西放在 `GuildScenery.PEOPLE_LAYER`，關卡讓諾恩與席菈多撞這一層（`collision_mask |= …`）。窗外沒有場景：玻璃上畫天色與街對面房子的剪影（`guild_window.gdshader`）；大門的洞外面是一條畫出來的街（`guild_street.gdshader`，不受光）。窗照進來的光是 `WindowLight` 的面片（光柱、地上的窗影），不是燈——**聚光燈＋投影貼圖（`light_projector`）在雲端的軟體算圖底下整盞不亮**（11/19 試過，白貼圖也一樣），驗收不了，先不用。門板是一片面：試過加厚度，開場鏡頭在南牆外面，門板的背面整片擋住畫面。
- **場景裡站著的人**：`Npc.create(節點名, 角色 id, 位置, 面向的角度)`，要他走就 `walk_path([幾個點], 速度)`（直線走、不繞路，點自己排）。要他講話就在開始對話前把他放進 `TalkCamera.cast`——人多的關卡每一段對話重排一次（看 `GuildHall._talk`：第一個是諾恩，第二個是諾恩這一段面對的人）。
- **換關卡前播一張卡**：`ChapterCard.play(關卡, 小字的翻譯 key, 大字的翻譯 key, Game.go_to_checkpoint_level)`（結尾給 `Game.back_to_title`）。關卡留著那張卡（`card`），測試叫 `card.finish()` 就不用等。
- **Quaternius 的 CC0 小物**：`scripts/gen_props.sh` 最下面的 `QUAT` 加名字（建置時從 `art-inbox/props/` 連貼圖複製到 `game/assets/props/quaternius/`，不進 git）→ `PropModels.instance("quaternius/<名字>")`。掛在牆上的（`Lantern_Wall`、`Shield_Wooden`）從原點往 +Z 伸出來，旗子（`Banner_1`）的桿子往 +X。
- **這一關不能動手**：關卡設 `player.peaceful = true`（出手、釋放的按鍵沒有反應）。
- **Boss**：繼承 `EnemyActor`、加進 `"boss"` 群組（`BossBar` 會畫牠的生命條）；多招寫在 `tuning.json` 的 `<id>.moves`／`pattern`，`_on_strike()` 照 `brain.move_id` 判定。打到一半要演的事（吼、凝視）用 `_held()` 把狀態機停住；階段寫成純邏輯（看 `GolemPhases`），生命不能低於某個值用 `Health.min_hp`。
- **收尾的一刀要特寫**（看 `RuinedAltar._on_core_shattered`）：`Game.hit_stop(定格秒數, 慢動作秒數, 慢動作倍率)` 先定格再用慢動作演一段；同一刻 `FinisherCamera.play(關卡, 出手的人, 挨打的人, 停幾秒, 離多遠, 多高, 看多高[, 不算遮擋的碰撞體])` 切到兩人的側面，演完自己把鏡頭還給玩家（對話一開始也會馬上讓開）。畫面中間還有字的話先 `Hud.hide_center_lines()`。
- **飛出去的碎塊**：`RockDebris.burst(關卡, 位置, 方向, 幾塊, 多大, 顏色, 初速的範圍[, 自己多亮])`。**掛在關卡上的一次性特效**加進去的時候用 `add_child(節點, true)`：同名的會被編成 `名字2`、`名字3`（不加的話是 `@MeshInstance3D@123`，測試找不到）。
- **面向鏡頭的加法光片**（`core_flare.gdshader`）：shader 要寫 `fog_disabled`——不寫的話整片（連沒有光的四個角）都會加上一層霧的顏色，看得出是一塊方的；光片插在身體裡會被切碎，所以畫的時候往鏡頭拉近（`pull`）。位置不要用骨頭掛點自己的軸（每個模型不一樣；魔像的胸口掛點 −Z 是朝上），用掛點的位置＋`Puppet` 的方向；離骨頭多遠要從側面看過（魔像的核心第一版離胸口太遠，正面看不出來，側面看是浮在半空中的一顆球）。
- **倒在地上的人**（雷歐小隊）：站著的模型整個放倒（`Puppet` 繞 X 轉 ±90°），外面包一個節點、原點放在胸口；要他講話就在那個節點設 meta `TalkCamera.DROP_META`（比站著矮多少），對話鏡頭會跟著放低。
- **把一次性動作停在某一刻**（魔像舉著拳頭等在那裡）：`Puppet.hold_action("attack", 第幾秒)`，`release_hold()` 放開。
- **蓋在身上的一層光要在離開場景樹時拿掉**（`_exit_tree`）：材質是角色腳本的變數，角色被釋放時材質比身上的網格先沒，引擎會報「material is null」（諾恩霸體無敵的金光、席菈被石化的灰都遇過）。
- **森林的外圍是土坡**（`ForestMap.height`，只是畫的、碰撞是平的）：離路網 16 m 以內一律是平的。森林裡要放東西在離路更遠的地方，高度用 `ForestMap.ground_y()`（跟 shader 讀的同一張高度圖；樹用 `ForestScenery.on_ground()`）。可以拿、可以用的東西腳下加 `ForestScenery.pickup_ring(半徑, 顏色)`（節點名 `PickupRing`；用過收起來）。
- **森林裡加東西**（自由探索）：位置寫在 `ForestExplore` 最上面的常數——可以採的毒蕈 `MUSHROOM_SPOTS`、噴發口 `VENT_SPOTS`、蜘蛛網 `WEB_SPOTS`（x、z、張開的方向）、野果 `BUSH_SPOTS`、敵人 `PACKS`（一群一個名字，每一隻寫種類與位置；種類在 `_new_enemy`）。要加一塊空地或一條路改 `ForestMap.CLEARINGS`／`PATHS`（樹、草、地面的土路會自己跟著）。東西要加在關卡底下（`level.add_child`），目標指引才找得到。
- 走近按鍵的東西：`Interactable.create(節點名, 位置, 提示的翻譯 key[, 範圍])`，把模型加成它的子節點，接 `used`；不能用了設 `enabled = false`。提示的字裡 `{key}` 會換成按鍵。
- 右上角的目標清單：任務階段加 `"checklist": [{"text": 翻譯 key, "flag": 旗標, "need": 5}, {"text": …, "flag": …, "optional": true}]`（`QuestRunner.checklist`）。
- 任務階段沒變的時候要存檔（採到東西、休息）：`Game.session.autosave()`。重來的位置在 `ForestExplore.RESPAWNS`（旗標 `ch1.respawn`）。
- 新武器：`PlayerController.WEAPONS` 加一筆（模型、砍中時給自己的來源、傷害倍率的 tuning key），`player.equip(id)` 換（記在旗標 `noen.weapon`）。
- 對話的演出寫在對話資料（`emote`／`act`／`shot`／`head`，認得的值在 `DialogueDB.EMOTES`／`ACTS`／`SHOTS`／`HEADS`）。新的漫符：`DialogueDB.EMOTES`、`MangaMark.KINDS`／`LOOK`（大小、擺在頭的哪裡）、`manga_mark.gdshader` 多一個 `kind` 的分支（顏色照畫面上看到的寫，shader 最後換成線性）。新的手勢：`social_actions` 加關鍵影格（手要到哪先用 `measure_action.py` 量；右手常拿武器，碰身體、揮手用左手）、`Puppet.ACTION_TIME`／`GESTURES`／`STATES`、`CharacterModels.ANIM_MAP`、`DialogueDB.ACTS`。看漫符：`--level=guild_hall --return --at=0.2,-2.2 --talk-skip=N`（1 驚嚇線、4 陰影線、5 低頭＋臉紅＋兩人同框、6 抬頭＋臉紅、7 閃亮）、`--after-leo --demo=quest --talk-skip=2`（問號）。
- 新的對話角色：關卡在 `TalkCamera.cast` 登記「說話者的翻譯 key → 那個角色」（看 `CorruptForest._spawn_sera`；同一個人有兩個名字就登記兩筆，例：還沒自我介紹的 `SPK_UNKNOWN`）。沒登記的說話者鏡頭不動。角色有 `talk_to(位置)` 的話，對話開始時會被叫去面向對方。
- **測試不動玩家的設定檔**：測試中存的設定寫到 `user://settings_tests.cfg`（跑完刪掉）。2026-11-17 以前是存在真的 `user://settings.cfg`，跑完會留下 `auto_attack=false`、`locale=en`（同一台機器接著拍戰鬥，諾恩不會自己砍）——機器上留著舊版測試寫的設定檔的話，把 `~/.local/share/CursesTooUseful/settings.cfg` 刪掉再拍，或加 `--tap=attack`。
- **測試預設關掉自動攻擊**（`tests/run_tests.gd` 每個測試開始前都設 `Settings.auto_attack = false`——有的測試會重讀設定檔，把它讀回預設的「開」）：測試自己擺位置、自己叫諾恩出手；要測自動攻擊的測試自己打開。遊戲裡預設是開的——用開發旗標拍戰鬥時諾恩會自己砍。
- 操作提示有提到「按哪個鍵攻擊」的，另外加一句 `<翻譯 key>_AUTO`（自動攻擊開著時 `Hud.hint_key_now()` 會改用它；沒有這一句就照原本的）。
- 任務階段的操作提示：階段加 `"hint": "<翻譯 key>"`，字裡的 `{attack}`、`{dodge}` 這類動作名（`InputSetup.ACTION_KEYS`）與 `{move}`、`{look}` 會換成現在裝置的按鍵（`Hud._refresh_hint`）。
- 會走路的角色要腳步聲：接 `Puppet.footfall`（腳落地的那一刻）呼叫 `Footsteps.stomp()`，不要照距離算（看 `PlayerController`）。
- 新敵人：繼承 `EnemyActor`，覆寫 `tuning_id()`、`_build_body()`、`_on_strike()`，數值加在 `tuning.json`（看 `Slime`）；在野外的寫 `leash`（追得離家多遠就回去，不寫＝不回家）。只是換模型、數值、撞到上的狀態：繼承 `Slime` 覆寫 `tuning_id()`／`model_name()`／`touch_source()`（看 `MoldSlime`）。森林裡有毒的敵人建好外型之後叫 `add_toxic_glow(外型)`（螢光綠的邊與腳下的燈，D-288；邊掛在材質的 `next_pass`，`material_overlay` 留給硬撐的紅光），蓄力時用 `_set_glow()` 調亮。四隻腳的覆寫 `_on_died()`（共用的「向前撲倒」會變成倒栽蔥，看 `MiasmaWolf`）。
- 敵人的模型：雙足、Tripo 的 mixamo 骨架 → 跟人物一樣走 `gen_art.sh`（加 `SRC`／`ARGS`（怪物加 `--keep-rest --no-social --monster`）、`import_characters.py` 的 `KNOWN`、`check_character_glb.py` 的 `BUDGETS`），遊戲裡用 `Puppet`（看 `SporeTreant`：走路照速度播、出手的第三段當下砸）。四足、Tripo 自己的骨架（`_anim.glb`）→ `gen_props.sh` 的 `QUADS` 加一行（`tools/blender/tripo_quadruped.py`：轉向、縮放、落地都放在外面多包的一層空物件上——骨架物件自己的位置與旋轉會被動作蓋掉），遊戲裡 `PropModels.instance` 之後找 `AnimationPlayer` 播 `walk`。
- 測試裡把敵人停住（`set_physics_process(false)`）要小心：停在前兆、出招那一格的敵人會一直佔著「同時只有一個人出手」的名額，別的敵人永遠不出手。要換下一隻就把前一隻打倒。存著敵人的陣列在牠們被釋放之後不能用有型別的迴圈變數走（`for e: EnemyActor in …` 會報錯），先 `is_instance_valid` 再轉型（看 `ForestExplore.pack_alive`）。
- 新角色模型：`scripts/gen_art.sh` 的 `SRC`／`ARGS` 加一行、`scripts/import_characters.py` 的 `KNOWN` 加 id，場景裡 `Puppet.character_id = "<id>"`。轉檔會先把 Tripo 的 T 字站姿扳正（`tripo_character.py` 的 `straighten_rest`：腳尖最多外開 7°、腿最多張 4°、大拇指轉到朝前＝手放下來手心朝大腿），不然走路外八、手心朝前；怪物（張腿、握拳是設計）在 `ARGS` 加 `--keep-rest`。扳的是休息姿勢，手上的掛點不受影響。
- 出手的動作：`tools/blender/common.py` 的 `standard_actions` 裡三段 `swing(拉開, 砍到, 帶過去, 踏幾步)`（`light_attack_01～03`；右手是 `(hang, swing, elbow[, turn])`，橫掃要手臂抬到肩膀高再 `turn`）。遊戲的命中判定在出手後 0.19 秒，劍要在 `T_HIT` 之前砍到位。**劍要在身體右邊或頭上揮、劍身橫對著鏡頭**（D-284）。改的流程：先量再拍——寫一個暫時的測試（照 `test_slash_trail.gd` 最後一個的寫法取每一幀的手與劍尖），投到假的過肩鏡頭（身體座標：後 3.4、高 2.1、右 0.5 m，看 (0, 1.0, −2)）算劍光帶子在畫面上的面積（每一段四邊形投到 3.4 m 外那一面、用叉積算；11/19 量到：第一下 0.58、第二下 0.33、收尾 1.31 m²），`ART_ONLY=noen scripts/gen_art.sh && python3 -P scripts/import_characters.py`、import、跑那個測試，一輪約 20 秒（11/19 用一個小腳本把「換一組角度 → 轉檔 → 量」串起來，一次試好幾組）；改 `common.py` 會讓**每個角色**下一次 `check.sh` 都重轉（約多 3 分鐘）；數字過了才用 `--joined --at=0,-5 --burst-on=combo`（`BURST_EVERY=4 BURST_COUNT=24`）連拍，從 `build/burst/.burst-<名字>/f-N.png` 原尺寸裁出諾恩看（240 px 的小圖看不出好壞）。`Puppet.attack_variant` 選第幾段，模型沒有那一段就播第一段。
- 新的人物動作：`tools/blender/common.py` 的 `standard_actions` 加一段（每個角色都會有）、`CharacterModels.ANIM_MAP` 與 `Puppet.ACTION_TIME`／`STATES` 加名字、程式人偶補一個最簡單的姿勢（看 `shoot`）。只有人用得到的（坐、笑、扛東西……）加在 `social_actions`（怪物在 `gen_art.sh` 的 `ARGS` 寫 `--no-social` 就不做）；循環的動作也加進 `CharacterModels.LOOPING`。角度先量再拍：手要到哪裡（例：舉杯到下巴前、扛東西的手在肩膀上面），寫一個小腳本載入轉好的 glb、用 `Animator.arm_pose` 試幾組角度、印手腕相對肩膀的位置，挑最接近的；再用 `tools/blender/preview.py` 看一眼（`social_actions` 的舉杯與扛東西就是這樣定的）。
- 拿在手上但要保持直立的東西（客人的杯子、莉莉絲遞出來的委託單）：`UprightHeld.attach(模型, puppet.hand("R"), 那個人, 位移)`——直接掛在手骨上，舉杯時手骨頭的軸翻過去杯子會倒過來。
- 武器收起來（公會大廳）：`PlayerController.peaceful = true` 會把劍掛到胸口的掛點（背在背上，`SHEATHED_*`）；`Sera.holstered = true` 把手弩掛到骨盆的掛點（右腰，`HOLSTER_AT`）。設回 false 就回到右手。
- 對話鏡頭要從講話的人背後看他看著的人（巡察官往下看諾恩）：在講話的人身上設 meta `TalkCamera.LOOK_META`＝他看的那個角色，那個人講話時鏡頭改成過肩（`TalkCamera.over_shoulder`）。
- 新物件／武器模型：`scripts/gen_props.sh` 的 `ARGS` 加一行 → `PropModels.instance("tripo/<名字>")`（記得寫檔案不在時的替身）。只要模型下面那一截（噴發口只要底座）加 `--keep-below <高度比例>`。模型自帶一圈亮色草皮底座的（樹）加 `--moss-below <高度> --sink <公尺>`：草皮改塗成地面的苔色、底座邊緣埋進地面；苔色在 `tripo_prop.py` 的 `MOSS` 與 `forest_ground.gdshader` 的 `moss`，兩邊要一樣。 **Tripo 的模型接進來先看顏色貼圖是不是灰的**（預覽圖有顏色、模型沒有的情況發生過兩次：夜光毒蕈、祭壇）：是的話用 shader 照形狀上色（看 `ForestScenery.paint_mushroom`）或重產。會發光、旁邊又掛一盞燈的小物：模型放 `GLOW_PROP_LAYER`、燈的 `light_cull_mask` 不照那一層，不然近看被自己的燈打成一片白。
- 存檔格式要改：`SaveCodec.CURRENT_VERSION` +1、加遷移、加一個從舊 JSON 讀起的測試（現在 v6；看 `test_save.gd` 的 v5 → v6：主線後面接了新的階段時，把「做完」的舊存檔接回去。主線**前面**加階段不用遷移——半路上的存檔記的是階段的 id）。
- 主線前面加了新的一段時，後面的關卡要能直接進（開發旗標、測試）：關卡的 `_ready` 看到主線還停在前面的階段，就把前面的旗標都設起來（`GuildHall.skip_opening`，`CorruptForest` 與 `RuinedAltar.skip_to_altar` 都會叫）。
- 新狀態：`statuses.json` 加一筆（種類 dot／action／guard／bleed／aim；要會疊就寫 `stack_max`）＋翻譯 key＋`StatusHud._draw` 的圖示；一樣東西要帶兩種狀態就在來源寫 `also`。反轉的回饋不用接。
- 席菈的藥：來源寫在 `statuses.json` 的 `sources`（要別的顏色就寫 `color`，沒寫是紫的）。她自己射的是 `Sera.vial_source`（關卡可以換；給了 `vial_cycle` 就照順序輪流），玩家按鍵要的是 `Sera.ask_source`（預設 `ASK_SOURCE`），關卡給了 `ask_extra` 就多一瓶可以換（`ask_choice()` 是現在要的那一瓶）；藥名、她回的話寫在來源的 `name`、`ask_bark`；射出去的那一刻發 `fired`；什麼時候可以要由關卡開（`Sera.ask_enabled`），她答不答應接 `Sera.asked`。
- 劇情演到某一拍才開放的操作，要在左上多寫一行提示：`Hud.set_extra_hint(翻譯 key[, 要填的字])`（任務階段的 `hint` 是整個階段固定的，寫不到；第二個參數填按鍵以外的東西，例：`{"sec": 7}` 對應字裡的 `{sec}`）。
- 換武器：劍光不用調——劍尖的位置從武器模型的外框算（`PlayerController.blade_tip`），顏色與大小在 `SlashTrail` 的常數，哪一段動作有劍光是 `PlayerController.trail_window(第幾下)`（結束都是 `TRAIL_WINDOW.y`，開始每一下自己的 `TRAIL_STARTS`：劍尖在畫面上幾乎不動的那一段不要記，十幾段疊在一起會多一塊厚光）。
- 刀痕的方向、顏色、大小是出手的人放在傷害的 `info` 裡的：`cut`（劍往哪裡掃，`PlayerController.blade_sweep()` 從劍光的取樣算：劍尖最近 `SlashTrail.SWEEP_SEC` 秒走的方向，照時間取、跟幀率無關）、`gold`、`heavy`。別的會砍人的東西（之後的同伴、Boss 的武器）要刀痕就帶 `cut`，不帶就沒有。
- 新的敵人不是人的體型時要改命中點：`EnemyActor._hit_height()`／`_hit_radius()`（預設是人的胸口 1.05 m；`Slime` 改成身體中間）——命中的閃光、碎屑、刀痕都生在那裡。
- 要貼著「這一幀的姿勢」的特效（劍光）：用 `Puppet.joint_now("hand_R")` 從骨架現算，並把自己的 `process_priority` 排在動畫後面；直接讀掛點節點的位置會慢一幀。
- 武器打中人時給自己的狀態：`PlayerController.on_hit_source` 填資料表的來源（現在是鏽劍的 `rusty_sword_cut`）；換武器就換這個。
- 關卡裡要有人喊一句（不停下遊戲）：`Hud.show_bark(講的人, 翻譯 key, 秒數, 名字的翻譯 key)`（給了名字，講的人不在畫面裡時會改放畫面下方「名字：台詞」）；要玩家選擇的才用對話（`Game.start_dialogue`），對話要改旗標寫在對話資料的 `do`。
- 換動作時混多久：`Puppet.blend_for(狀態)`（出手與釋放 0.05 秒、其他 0.15 秒）。出手的拉開只有 0.09 秒，混得比拉開久就看不到拉開。
- **怪物的動作**（魔像、樹人；D-303）：`tools/blender/common.py` 的 `monster_actions`（`gen_art.sh` 的 `ARGS` 寫 `--monster` 才做），跟人的動作同一套 `Animator`。出招（`punch`、`hammer`）做成「0～`MONSTER_APEX` 舉起來 → 停在頂 → 0.19 秒打下去 → 收回來」，遊戲在前兆一開始 `Puppet.wind_up(名字, brain.telegraph_sec)`、前兆剩 `Puppet.STRIKE_LEAD` 秒時 `release_hold()`；`MONSTER_APEX` 在 `common.py` 與 `Puppet` 各寫一次，要一樣。不知道要多久的（吼、凝視、跪）做成「做到位 → 撐著 → 收回來」，`play_action(名字, 秒數)` 整段縮放。改角度先用 `pose_sheet` 那種小腳本在 Blender 裡拍幾格（workbench、斜前與側面兩張；魔像 3.6 m 要把鏡頭拉遠），數字過了再連拍。新的怪物動作：`monster_actions` 加一段、`Puppet.ACTION_TIME`／`STATES`、`CharacterModels.ANIM_MAP`、程式人偶的替身姿勢（`_pose` 的 `match action`）。

### 聲音放在哪

- 音檔全部由 `scripts/gen_sfx.py` 產生（開頭有分組的清單，每個音的樣子寫在自己的函式說明裡）；新的音：寫一個函式、`main()` 加一行 `write(...)`、`Sfx.NAMES` 加名字（打包驗證照這份清單檢查），沒有人播的就從兩邊拿掉、加進 `test_sfx.gd` 的「已經沒有人播」。
- 整片的環境音：`CorruptForest`（`ForestNight`）、`RuinedAltar`（`AltarAir`）、`GuildHall`（`HallMurmur`）。從東西發出來的：`ForestExplore._loop_sound`（`FIRE_SOUND`／`VENT_SOUND`／`SWAMP_SOUND`＝[音檔, dB, unit_size]）。
- 配樂：`Boot`（標題）、`GuildHall.hall_music`（`_music_to(音量, 秒)` 調大小，警報停、雷歐走了回來、章末收掉）、`RuinedAltar.boss_music`（醒來淡入、`_fade_out_music`）、`GuildHall._play_end_card`（結尾）。
- 敵人的叫聲：`EnemyActor.notice_sfx()`（第一次離開待機叫一聲，空字串＝不叫）、`fall_sfx()`（倒地，預設 `blunt`），子類別覆寫；`last_notice_sfx`／`last_fall_sfx` 給測試看。
- 魔像的聲音都經過 `PlagueGolem._sound()`，最近的 24 個記在 `heard`（測試看這個）。漫符的聲音是 `MangaMark.SOUND`，由 `TalkActing` 在對話裡播（`last_sound`）。
- 流程測試的 `_playing(節點, 音檔)`：那個節點底下有沒有正在播這個音的播放器（缺檔時當成有）。
